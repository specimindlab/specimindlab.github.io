# Series fixtures

Design fixtures for the Remotion Studio and visual QA (`scripts/render_series_test.sh`). **Not research.** Tool names come from the draft calendar, numbers are placeholders, media are our own drawings in `video/public/test/`. Never copy values from here into an episode: every fact in a real script.json comes from that episode's research.md and facts.json.

`catalog.fixture.json` stands in for `data/catalog.json` in the Drawer fixture only; real renders always read the real catalog.
